# Informe VIVSO 2026 — copia pública

Sitio estático con el informe de solicitudes de inclusión al programa de vivienda
(OG / ONG), enero–septiembre 2026. Generado a partir de GDE y VISOC.

Esta es la **copia pública** (sin DNI ni nombres de personas): los campos de texto
libre que en la copia interna traen el detalle textual de cada expediente/reclamo
fueron reemplazados por su clasificación ya calculada (estado de pago, etc.) o por un
texto genérico. Ver el repositorio de origen del proyecto para el detalle de cómo se
generan los datos y las decisiones metodológicas.

Para verlo: abrir `index.html` (o servirlo con GitHub Pages).
